1. Introduction

The HMS-GW-S3 gateway reads live data from your Hoymiles HMS-800W-2T solar inverter and makes it available through a built-in web dashboard — no app, no cloud account, no installation required. Just open a browser and point it at the gateway's IP address.

This guide covers everything you can do from that dashboard: monitoring live solar output, controlling the relay and auxiliary IOs, changing WiFi/MQTT/network settings, and updating the firmware.

Also availableA companion Progressive Web App for viewing and controlling the gateway from outside your home network is covered briefly in §7 and described in full in the project's README.

What you need

  • A device with a modern web browser (phone, tablet, laptop, desktop — any OS)
  • The gateway connected to your WiFi network (see §2 if this is a first-time setup)
  • The gateway's IP address, or its factory-default access point if it isn't on your network yet

2. Getting Started

2.1 First connection (factory-new device)

Out of the box, the gateway cannot yet know your home WiFi credentials, so it opens its own temporary access point:

  1. On your phone or laptop, open the WiFi settings and connect to the network named HMS-GW-S3. No password is required.
  2. Open a browser and go to http://192.168.4.1.
  3. The dashboard loads. Switch to the Config tab (see §5) and enter your home WiFi network name (SSID) and password under the "WiFi" section.
  4. Click Save. The gateway restarts and connects to your home network.
NoteOnce connected to your home network, the temporary HMS-GW-S3 access point disappears — you'll need the gateway's new IP address to reach it again (see below).

2.2 Finding the gateway on your network

After the WiFi setup above, the gateway gets its address from your router (DHCP) unless you configured a static IP. The most reliable way to find it:

  • Open your router's admin page and look at the list of connected devices for one named HMS-GW-S3 (or similar).
  • Alternatively, check the gateway's status LED behaviour or serial console output if you have access to it (see the project's technical specification for LED colour meanings).

There is no .local hostname — the gateway must be reached by its numeric IP address (e.g. http://192.168.1.42).

2.3 Bookmark it

Once you know the address, bookmark it in your browser for quick access later. If you later assign the gateway a static IP (Config tab → Network), that address won't change again.

3.2 Status card

Shows one of four states, colour-coded (see §9 for the full colour legend):

LabelMeaning
ActiveWiFi, DTU and MQTT are all connected, and the inverter is currently feeding power into the grid. Shown in cyan.
StandbyEverything is connected, but the inverter isn't producing right now (e.g. at night, or too little sunlight).
No dataEverything is connected, but no reading has arrived yet (briefly shown right after startup).
OfflineWiFi, the DTU link, or MQTT is not connected.

3.3 Power Limit card

Lets you cap how much power the inverter is allowed to feed into the grid, as a percentage of its rated output.

  1. Drag the slider to the desired percentage.
  2. Click Set to send the new value.
  3. The card border turns pink while the change is in flight, and back to cyan once the inverter confirms it (usually within a few seconds).
TipIf a sent limit never turns cyan, the inverter may be unreachable (e.g. the DTU link is down) — check the Status card and the DTU settings in the Config tab.

3.4 Temp / Limit / Yield today / Total cards

Inverter temperature, the currently confirmed power limit, and today's/all-time energy yield across both PV strings and the grid connection combined.

3.5 Grid / PV1 / PV2 cards

Live power (W), voltage and current for the grid connection and each of the two PV strings. The card border and the power figure change colour depending on the current output level — see §9 for exact thresholds. This gives you an at-a-glance sense of how much each string is producing, even from across the room.

3.6 Header

At the top of every page: three status dots (WiFi / DTU / MQTT — lit when connected), a language toggle (DE/EN), and an info bar showing the device's MAC address, firmware version and build number, plus the current date and time.

5. The Config Tab

All device settings live here, grouped into boxes. Change what you need, then click Save at the bottom of the page — the gateway restarts to apply the new configuration. Reset discards unsaved changes and reloads the current values from the device.

5.1 WiFi

FieldDescription
SSIDYour WiFi network name.
PasswordYour WiFi password. Leave the field as-is to keep the current password unchanged.
AP fallback if no STAIf enabled, the gateway re-opens its own HMS-GW-S3 access point whenever it can't reach your home WiFi — useful if you ever need to reconfigure it without physical access.

5.2 Network

FieldDescription
Static IP addressEnable to give the gateway a fixed address instead of one assigned automatically by your router (DHCP). Recommended once everything is working, so the address never changes.
IP Address / Subnet Mask / GatewayOnly used when static IP is enabled. The gateway address is also used as the DNS server.

5.3 DTU (Hoymiles)

Connection settings for the inverter's built-in DTU (data transfer unit). These are normally pre-configured correctly and rarely need changes — the poll interval and reconnect behaviour can be tuned here if needed.

5.4 MQTT

MQTT lets the gateway publish live data to a broker, for use with Home Assistant, the mobile app, or any other MQTT client.

FieldDescription
Broker Host / PortAddress of your MQTT broker. Port switches automatically between 1883 (plain) and 8883 (TLS) when you toggle TLS.
Username / PasswordBroker login credentials, if required.
TopicPrefix under which all data is published (defaults to a unique hmsgws3_XXXXXX per device).
TLSEncrypts the connection to the broker — required for brokers reachable over the internet.
HA Auto-DiscoveryAutomatically registers all sensors/switches in Home Assistant — no manual YAML configuration needed.
OpenDTU modePublishes using the OpenDTU-compatible topic layout, for tools expecting that format instead of this gateway's own.
Retain (live values)Keeps the last live reading available to newly-connecting clients. Daily/total yield and relay/IO state are always kept available regardless of this setting.

5.5 Power Control

The default power limit applied on startup, and an optional timeout after which a manually-set limit automatically reverts to that default.

5.6 NTP & Time

The time server used to keep the gateway's clock accurate, and your timezone offset in seconds (e.g. 3600 for UTC+1).

5.7 Web Server

The port the dashboard itself is served on (default 80), and optional username/password protection for the whole dashboard.

ImportantPort and login-protection changes only take effect after the automatic restart. If you enable protection, your browser will prompt for the new credentials on the next page load — don't lock yourself out by forgetting them (a factory reset, §6.4, is the only way back in).

5.8 System

The onboard status LED's brightness, the verbosity of the serial diagnostic log, and the URL used for automatic Internet update checks (§6.3).

6. The System Tab

Firmware updates, backups, device information, and administrative actions.

6.1 Firmware / Filesystem OTA (local upload)

If you have a firmware file (firmware.bin) or filesystem image (littlefs.bin) downloaded to your device, you can flash it directly:

  1. Click Choose File and select the .bin file.
  2. Click Flash. A progress bar shows the upload.
  3. The gateway restarts automatically once the update completes.
Both parts matterFirmware and filesystem are updated independently. A release usually needs both flashed — flashing only the firmware can leave the dashboard page itself outdated even though the device logic is current.

6.2 Internet Update

Checks a version manifest online and offers a one-click install if a newer release is available — no file download needed.

  1. Click Check.
  2. If an update is available, an Install now button appears — click it to download and flash both firmware and filesystem automatically.
  3. If you're already on the latest version, this is shown clearly instead.

6.3 Backup Configuration

Download Backup saves all current settings to a .json file on your device — handy before a factory reset or when setting up a second gateway. WiFi, MQTT and web passwords are not included in the backup; you'll need to re-enter those after a restore.

To restore: choose a previously-downloaded backup file and click Restore. The gateway applies it and restarts.

6.4 Device Information

A read-only summary: firmware version and build number, MAC address, IP address, WiFi signal strength, uptime, free memory, and current NTP time.

6.5 Danger Zone

ActionEffect
RebootRestarts the device. All settings are kept.
Factory resetErases all configuration, including WiFi credentials — the device restarts and opens its own HMS-GW-S3 access point again, as if brand new (§2.1).
Before a factory resetDownload a configuration backup first (§6.3) if you might want your settings back afterwards — a factory reset cannot be undone.

7. Remote Access (Mobile App)

The web dashboard covered in this guide only works while your device is on the same local network as the gateway. For access from anywhere — e.g. checking your solar output while away from home — a companion Progressive Web App is available at app/ in the project repository, or hosted at the project's GitHub Pages URL.

It talks to the gateway indirectly through a cloud MQTT broker instead of connecting to it directly, so it needs a one-time broker setup first (see the project README, section "Cloud MQTT Broker Setup"). Once configured, it offers the same live view and the same controls (power limit, relay, IO) as this web dashboard, installable as a home-screen app on both Android and iOS.

8. Troubleshooting

I can't find the gateway on my network

Check your router's connected-devices list for HMS-GW-S3. If it's not there at all, it may still be in its own access-point mode — look for a WiFi network named HMS-GW-S3 and connect to it directly (§2.1).

I forgot my WiFi password / can't reach the device at all

If you have physical access to the device, a factory reset (§6.5) clears the WiFi configuration and re-opens the setup access point. There is currently no remote recovery if you can't reach the dashboard at all.

MQTT won't connect

Double-check host, port, username and password in Config → MQTT (§5.4). If using TLS, make sure the port is 8883 (or your broker's TLS port) and that the broker's certificate is trusted by the gateway (see the technical specification for CA-certificate setup).

An OTA update failed or the device won't boot after one

The gateway keeps the previous firmware as a fallback and will not brick from a failed update in normal operation. Power-cycle the device and try the update again; if problems persist, flash both firmware and filesystem locally via USB as described in the project README.

I'm locked out after enabling web login protection

A factory reset (§6.5) is the only way to clear a forgotten dashboard password if you don't have another way in.

9. Appendix: Status Colour Legend

The dashboard uses a small, consistent colour language throughout — once you know it, every screen reads at a glance:

Cyan — active / connected / confirmed Violet — mid-range value / settings Pink — inactive / disconnected / pending / needs attention

On the Grid/PV1/PV2 cards specifically, colour also reflects the current power level (roughly: cyan at low output, violet at moderate output, pink near the string's maximum) — this is a visual cue only and does not indicate a fault.
